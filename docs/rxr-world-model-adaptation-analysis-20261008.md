# RxR世界模型适配分析（2026-10-08）

## 判断

建议准备RxR相机条件下的适配微调，但尚不能凭配置差异断言必须从头训练。先修正相机合同并测量原模型预测质量。现有RxR配置复用同一75k世界模型，不代表适配已经验证；最近150点测评关闭世界模型和二阶段，不能用其结果证明兼容。

## 核对事实

- 当前任务入口`run_rxr/rxr_vlnce.yaml`：RGB224×224、HFOV63°、相机高0.88m，深度256×256、范围0.5—5m，转角30°，评测不滑动。不要混用旧的其他RxR配置。
- R2R入口`run_r2r/r2r_vlnce.yaml`：RGB224×224、HFOV90°，高度经`common/environments.py`桥接默认为1.25m，转角15°。分辨率相同不代表相机内容相同。
- 训练机只读确认当前世界模型链接到`/mnt/data2tb/RAE-NWM/raenwm/logs/raenwm_mp3d_h125_224_96_e50_fresh_cls_20260617/checkpoints/checkpoint_step_75000.pth.tar`。
- 原工程`raenwm/config/raenwm_mp3d_h125_224_e50_fresh_20260612.yaml`使用4帧、CLS+patch、224输入；采集`tools/data/mp3d_full_run_h125_224/collection_summary.json`确认90°、1.25m。训练坐标尺度为0.24975892673356762m，与ETP-R1适配器一致。
- `predictor.py:_predict_time_from_latents`输入历史视觉特征、相对位姿及跨度，没有语言、HFOV或相机高度条件。不能仅改一个配置值让权重自动适配新的相机。
- `common/environments.py:_render_nwm_rgb_views`使用实际rgb传感器，动态读取其偏移，因此RxR直接渲染实际为63°/0.88m。注释中的1.25不是强制校准。备用cube路径的`panorama_context.py`及`panorama_runtime.py`仍假设90°方形立方体面，直接把RxR63°图当90°面会造成投影错误。trainer内90°修改属于视频展示传感器，不解决这个问题。
- 当前第二阶段后继路点预测器链接到`/mnt/data2tb/dino_cwp/outputs/single_view_dino_cwp_training/query_transformer_etpnav_r2r_cwp_20260521/checkpoints/best.pt`。原工程研究记录与`tools/build_full_cache.py`确认其profile为224、90°、1.25m。ETP-R1的`dino_cwp_future.py`解码按30个3°角度格覆盖±45°，不能仅把输出角度乘63/90当作适配。
- 导航用路点预测器已按任务选择`check_cwp_bestdist_hfov63`或`hfov90`；它与第二阶段DINO-CWP是不同模块，前者切换不代表后者已经适配。
- 现有RxR native-cls E24 joint配置属于旧联合训练链路；当前R2R持久融合与离线stage2主线的迁移需要独立配置、采集及训练，不能把旧yaml当作完整迁移结果。

## 为什么及如何处理

视场变窄会改变图像尺度与可见范围，高度降低会改变遮挡、地面比例与视差。90°原始图可近似中心裁剪到63°再缩放，但不能修正1.25→0.88m的视点；CLS和patch特征也不能直接当作图像裁剪。维持RxR原任务相机，以0.88m/63°重新渲染图像最清楚。

推荐顺序：

1. 固定RxR基座和实际评测合同，明确相机参数，优先验证direct路径，给cube路径加正确标定或拒绝不支持的输入。
2. 在固定的少量训练/独立验证场景上采集RxR真实相机条件的历史与目标图像。离线真值仅用于训练/质量评估，不允许在线读取未来真值。
3. 比较原75k权重与直接复用历史图像特征的预测误差，按距离、转角和q0/q1分组；同时检查后继预测器有效率与路点误差。
4. 若原模型明显退化，从75k微调世界模型，先冻结DINO/RAE编码器并保持现有归一化尺度；坐标尺度需按新采样约定核对，不随意改动。重训/微调后继路点预测器并更新标签角度约定。预测改善再进入导航训练。
5. 在RxR基座上训练自身的第一阶段融合，重新采集自身第二阶段数据并训练评分头；最后同机同配置比较无世界模型、仅第一阶段、完整两阶段，不能直接部署R2R的6400/9200模型及评分头作为已验证方案。

4帧上下文、257×768特征形状、10步采样并无因RxR而必须更改的证据。转角、滑动、深度范围改变候选和运动分布，需检验，但不等于世界模型结构必须变化。RxR多语言由导航策略处理，不是视觉世界模型必须重训的直接理由。
