# E24 下一轮优化分析

2026-09-17。分析范围：已完成的预测future E24离线训练、实际模型/损失/采集源码，以及ETPNav历史优化记录。本次只读检查远端与CPU缓存统计，没有启动新训练、GPU评价或修改ETPNav。本文件记录建议，以下实验均未执行。

## 1. 判断：先解决信息缺失与训练目标，再扩模型

当前E24已有60854785参数、768维、8查询、3轮独立的文字/视觉融合与候选比较。它不是当年ETPNav最初的184万参数小模型。训练损失下降、开发集后期下降，说明继续加深或延长训练没有直接证据支持。

首轮固定g=1，4750步改对105、改坏81，净+24；18300步改对190、改坏230，净-40。最佳提升0.1793个百分点，配对路线重采样区间跨0。优先减少缺乏证据时的误改，再改善可纠正错误上的学习。

## 2. 本次新核查的证据

### 2.1 收益与损失来自不同样本

下表“教师有future”是离线标签诊断，不是部署可用开关。

| 开发集组别 | 行数 | 4750步改对/改坏/净值 | 18300步改对/改坏/净值 |
| --- | ---: | ---: | ---: |
| 教师候选有有效future | 7586 | 105 / 26 / +79 | 185 / 150 / +35 |
| 教师候选没有有效future | 5803 | 0 / 55 / -55 | 5 / 80 / -75 |

第二组中2392行完全没有future，始终零变化。另有3411行存在其他候选的future：2105行教师在Top-5但它的future缺失，1306行教师不在Top-5。前者的教师future缺失原因：1159次CWP none，946次缺少q0。不能把这些统计泛化成全部查询的失败原因分布。

有1945行“基础赢家缺少future，但别的候选有future”。当前 `collate_stage2` 把future有效性作为 `topk_valid_mask`，head又把它用于候选交互、赢家参照等。于是缺future的候选虽然参与最终全候选决策，却缺席部分内部比较。这是应做对照的结构限制，不等于已证明的实现错误。

### 2.2 分数修正越来越强

| 指标（沿用当前报告统计口径） | 4750步 | 18300步 |
| --- | ---: | ---: |
| 有效槽平均修正绝对值 | 0.676 | 0.843 |
| 修正绝对值≥0.99的比例 | 35.63% | 59.93% |
| 主要移动决策翻转率 | 2.76% | 6.45% |

模型后期更加频繁、大幅地改分，但增加的纠错赶不上增加的误伤。不能仅凭此认定“门控一定有效”，但值得先验证幅度约束、方向损失与可靠性建模。

4750步时基础第一、第二名分差小于0.5的组净+29，0.5至1组净-5，≥1组净0。该分差不是教师与赢家的分差，不能据此推断所有可纠正性。也不能观察这张表后无限搜索分差阈值并当作泛化提升。

### 2.3 损失没有充分覆盖预测缺失情况

实际代码 `stage2_training.py` / `offline_objective.py` / `direct_loss.py`：

- 分类与配对排序要求教师候选在有效future集合中。
- 教师在Top-5但没有future时，方向损失跳过该行；主要只剩权重0.05的少改动平方约束。
- 教师在Top-5之外时，存在全部负向的方向监督与少改动约束，但主要分类/排序仍跳过。
- 能否在残差上限内纠正已被计算，却目前只用于日志计数，没有控制分类/排序的训练权重。
- 正确/错误基础决策权重为2/1；方向损失权重0.25，残差平方权重0.001。

这些是继承旧冠军的设计选择。旧真值future缺失较少，本轮预测future缺失更多，应该重新验证这些选择，而非称旧设计在所有场景都错误。

### 2.4 仍有理论纠正空间

在测评机专用容器/环境中顺序读取完整dev缓存，CPU统计退出0。保持全部可执行候选、现有future mask、STOP隔离和±1残差边界；允许利用教师标签给每行独立选择最有利修正：教师若可修改则+1，其他可修改候选-1，再按原argmax规则判断。

- 主要决策13389行，基础正确8013、错误5376。
- 其中1008个错误在这一乐观边界下可翻转为正确。
- 859个的教师future有效；149个的教师future无效/未在查询集合中，仍可通过压低竞争者实现纠正。

这是标签知情、逐行自由选择残差的乐观上界，包括边界与并列规则影响，不是可部署模型，也不证明特征足以学习这些选择。它说明“只有±1所以没有空间”不足以解释当前结果；同样，教师没有future也不等于必然不可纠正。

### 2.5 训练与开发分布明显不同

| 指标 | train | dev |
| --- | ---: | ---: |
| 有效移动决策 | 70761 | 13389 |
| 基础决策准确率 | 约90.90% | 59.85% |
| 教师在Top-5 | 99.59% | 90.01% |
| 教师future有效 | 70.88% | 56.66% |

上述覆盖率分母均为有效移动决策。训练中教师future有效的50155行里，基础正确46364、错误3791；叠加2/1权重后，正确行占分类/排序样本权重总量约96%。这不是实际损失或梯度贡献占比，后者还取决于每行难度与批内归一化。

## 3. ETPNav经验应如何复用

只读核查训练机工作区 `/home/gwl/project/ETPNav/ETPNav/.worktrees/stage0-rgb17400-oracle`：当前 `docs/stage0-final.md`、冠军YAML，以及历史提交 `a197196` 中 `docs/experiments/2026-07-20-stage0-v2-offline-net-correction-optimization-log.md`。

- 当年的起点是184万参数、独立候选、仅方向监督，最好净+28。后来通过决策损失、显式几何、候选比较、交替融合、基座分差与权重组合、多种子、有限后处理逐步推进。
- 当前E24已继承大量后期结构和损失，不能把当年的每个成功改动再当作本轮新增贡献。
- 单纯加宽加深、无门控反馈、增加错误行比例，都未持续刷新冠军。E27错误比例×残差边界的四格对照没有超过旧+295冠军；持平组因误伤更多而落选。
- 旧冠军是seed2相邻三点平均并用g=1.206校准，净+295；独立校准器净+283，没有超过冠军。不能预设额外门控/校准网络必有收益。
- 旧冠军未来位置选择利用真实目标，未来视觉也是真实渲染；本轮q1由预测路点提出，视觉由世界模型预测。旧+295不是本轮应直接达到的可比目标，也不是导航成功率增益。

应复用的是“明确假设、单因素对照、固定预算、报告改对与改坏、失败也保留”的实验方法。

## 4. 具体优化方向

### A. 先做廉价诊断和幅度校准

1. 固定首轮已选出的4750/4000两个头，仅评价预设g网格 `{0,0.5,0.75,1,1.25,1.5}`，应用clamp(g×delta,-1,1)。最多12组合；g=0为合法零收益基线。只得到校准候选，不能声称重新训练出了结构提升。
2. 推理时遮蔽/打乱future作敏感性诊断；此操作会造成分布外输入，不能单独证明future没有作用。再训练一个同协议的“仅节点、指令、基础分数和几何”对照，判断额外未来信息的价值。
3. 可纠正性统计扩展到train及不同幅度上限，再决定是否测试1.25/1.5，不能因饱和率高就直接放宽上限。

### B. 优先改训练目标

保持网络、缓存和±1上限不变，先比较：

- 对教师有效、基础和教师均移动、且存在可修改候选的行，允许通过完整候选上的分类目标学习压低错误竞争者，不再把教师自身future有效作为统一前提。
- 将“教师未入Top-5”“教师入Top-5但future缺失”“完全无future”分别处理。完全无future行不更新；其他两类检查是否有可行纠正方向。不能将没有future的候选伪装成有效预测。
- 对当前边界下不可纠正的错误行，测试降低分类/配对权重，避免长期推到±1也无法换动作；仍保留计数及合适的保守约束。教师标签仅用于训练权重，部署不读取可纠正性标签。
- 之后单独测试方向损失0.25→0.1，或残差平方约束0.001→0.01。一次只改一个因素，确认哪种约束在压低误伤，防止把多个变化混成一个结果。

直接把错误样本拉到50%、大幅调高错误权重不是首选。若现有监督修正后仍缺乏纠错信号，再做有限的“可纠正错误/正确但容易被改坏/信息缺失”分层采样，训练标签只参与训练，评价保留自然分布。

### C. 模型结构：更合理地处理缺失，而非默认增大

1. **分开候选存在mask与future有效mask。** 所有真实Top-5候选可用已有节点、文字、几何和分数参与比较，只有读取future的注意力分支受future mask约束。第一版仍仅给原有future有效候选输出可执行修正，保持可修改动作集合不变；若要让无future候选也输出修正，另开实验，不能混入这一对照。
2. **显式编码查询条件与质量。** 当前已保存 `q1_conditions`，却未传给head；也有q0/q1位置、朝向、预测时域、q0来源步数和缺失原因。核对坐标与归一化后，可逐项加入q1相对几何、缓存年龄、有效槽数等信息。CWP原始置信度、跨噪声一致性若未保存，需要重采。
3. **小模型对照。** 先试hidden384、6注意力头、FFN1536、2轮、4查询，其余协议相同；实际参数量实现时记录。它检验当前60M容量是否放大过拟合，不预设小模型必胜。共享轮次参数是另一独立对照，当前实现硬限定独立轮次，需要新模式和兼容性测试。
4. **质量门控靠后。** 若诊断支持，令修正=可靠性系数×有界分数，可靠性只使用部署可见的缺失mask、分差、几何、预测质量等。不能用“教师future有效”当推理条件；不能只凭基座高置信度就拒绝改动，因为它也会高置信地犯错。若另训校准器，应使用折外头预测，避免用头在自身训练样本上的过度乐观输出教校准器。
5. **q0到q1的变化建模。** 可比较“前进一步后哪些证据改变”而非仅绝对q1外观，但当前缓存没有完整q0视觉tokens，不能只靠元数据补出此实验；需新数据版本。现有owner已经融合部分一阶段信息，先用消融判断新增变化特征是否有增量价值。

### D. 数据：补新信息，避免只复制更多相似记录

- 先修查q0缺失与CWP none的原因。none可能是合理拒绝，不能单纯降低阈值，把无效未来变成有效样本来追求覆盖率。
- 对同一批固定状态、同一个已预测q1位置，对比预测视觉与真实渲染视觉，隔离世界模型误差。若改用目标指导的q1，必须单列另一上界，不能同时改变位置与视觉后把差异全归给世界模型。
- 在train中采集更多分歧状态、不同预测噪声与有限动作扰动；未来预测始终不能读取教师或真实目标。路径/指令/场景关联样本不跨数据划分。
- 当前教师在一个ghost的多个真实位置中随机取代表位置再比较距离，而预测查询使用规定的q0位置。值得审计这是否造成标签不稳定；未证明它是本轮误差主因。
- 如教师多个候选近似等价，可考虑距离差/进度软标签。但当前缓存只有单个教师选择，缺少全部候选的真实代价；不能用基座分数冒充真实代价，需要重新记录教师侧信息，且不得把它输入模型。
- 离线改善稳定后，再用当前组合策略在train重新采集访问状态，冻结一阶段继续训E24。不要一开始同时更新一阶段和世界模型，否则难以归因。

## 5. 推荐下一轮实验顺序与预算

| 顺序 | 实验 | 复用缓存 | 主要回答的问题 |
| --- | --- | --- | --- |
| 0 | 两个既有头的有限倍率评价 | 是，不训练 | 是否主要是幅度校准问题 |
| 1 | 同协议无future训练对照 | 是 | 预测未来是否提供增量信息 |
| 2 | 缺失教师future行的决策监督 | 是 | 改进监督覆盖能否减少-55损失 |
| 3 | 候选存在/future有效mask解耦 | 是 | 缺失候选参照是否影响比较 |
| 4 | 384维小模型，与相同目标的大模型比 | 是 | 容量是否造成过拟合 |
| 5 | 只在优胜设置上做方向权重或正则单因素对照 | 是 | 控制过度改分是否有效 |
| 6 | 同位置真实/预测future诊断与定向重采 | 部分需重采 | 是否主要受查询和视觉质量限制 |

不一次展开结构×损失×学习率×采样比例的全部组合。先每组6000更新、同seed2、同数据顺序、每250保存；与现有baseline前6000步公平比较。只有末1000步仍持续刷新开发表现、且误伤没有显著上升时，按提前固定规则延长到10000。固定学习率2e-5先保留，降低学习率或改衰减作为后续单独因素。

筛选优胜设置后，在相同预算/选点规则下用3个预先固定的种子验证，并重跑对应baseline对照。报告所有种子、相邻点、每场景表现、错误转移与统计区间，不能只取最好seed。最终少数候选再接回完整导航，与同机基座对照SR/SPL/成本。

## 6. 数据划分与结论边界

继续把val_unseen称开发集，它已参与多轮选点，不能因重新命名或重分子集变成独立测试集。可在train中按场景留出用于E24内部筛选，但一阶段曾训练过这些场景，所以它不是整个系统的未见场景评测。若需要无偏结论，需真正未参与开发的评测资源；不能把开发样本加入训练。

教师future分组、理想残差与真实未来上界仅用于分析。部署门控必须只依赖真实可获取的信息。平均模型与额外门控并非必然有益；旧冠军权重热启动也只能另列对照，不能将旧Oracle训练数据混入新数据后不说明。
