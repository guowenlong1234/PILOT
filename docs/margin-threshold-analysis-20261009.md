# 前瞻分差阈值：配置、离线选择与导航验证

## 建议

推荐 `MODEL.STAGE2_ONLINE.margin_threshold = 1.0`。先计算所有可执行移动候选前两名的基础分差 m=s_(1)-s_(2)，只有 m≤τ（实现含保守数值余量）才继续二阶段前瞻。STOP、强制停止和单候选保持原跳过规则。严格上下界证书先检查，经验阈值只进一步筛掉尚未被证书排除的决策。

| 配置 | 行为 |
|---|---|
| `bounded_skip=True, margin_threshold=1.0` | 默认：证书＋经验分差阈值 |
| `bounded_skip=True, margin_threshold=-1` | 恢复只按严格数学证书剪枝 |
| `bounded_skip=False` | 完整二阶段，忽略阈值的跳过作用，但仍记录诊断 |

命令行 `scripts/stage2_e24_job.py` 对应 `--margin-threshold 1`、`--margin-threshold -1` 和 `--bounded-skip off`。阈值必须是有限非负数或特殊值-1；0表示仅保留并列/数值临界的决策，不表示关闭门控。1.0的单位是当前策略原始logit分差，不是概率或百分比，不保证跨模型/温度通用。

阈值写入YACS配置、完整启动命令、provenance、逐步gate_plan及online_summary。实际经验跳过记为`margin_threshold`，严格证明仍单独保存在`certificate`及`certified_*`计数中，不把经验门控伪装成动作不变性证书。旧严格剪枝基准脚本已显式锁定`--margin-threshold -1`，可复现原实验。

## 导航指标怎样判断

431次是“实际动作变化”，不是431次正确纠错。日志没有每个候选的教师价值，不能把全部改选都称为收益。

τ=0.75漏掉的4次改选来自4条路线，其中3条在完整前瞻中成功；τ=0.5涉及36条路线，其中18条完整前瞻成功。这只能说明可能影响的路线，不能推导会损失3或18条成功：改变动作后可能变好，也可能变坏。

对于τ=1，所有已记录状态上的选择都与完整前瞻一致，整条轨迹没有离线首个分叉。在模拟环境、随机流和数值计算一致的条件下，可以按时间步归纳保持相同轨迹。但删减批次会有GPU浮点差异，所以还需要实际导航验证，不能仅从日志推出新的实测SR/SPL。

完整前瞻归档的SR63.5672%、SPL54.2770%仅作为原策略参考值，不填写成阈值策略的新全量结果。阈值1的128路线实际验证已完成，见下一节；尚未对阈值1重新运行全量1839路线。

## 数学与论文表述

可以称为“分差门控的选择性前瞻”（Margin-Gated Selective Lookahead）。原严格证书是无需分布假设的安全外层，τ是控制计算量与决策保真度的超参数。在通常的统一边界、至少两个候选且0≤τ≤2B时，策略可概括为（省略数值余量）：

\[
g_\tau(s)=\mathbf1[m\le\tau],\qquad
\tilde s_i=s_i+g_\tau(s)\delta_i,
\quad |\delta_i|\le B.
\]

STOP隔离等原规则仍单独应用。当前B=1；统一边界下，m>2B时完整前瞻也不能改变赢家。τ<2B进一步减少计算，但不再具有对所有可能未来修正的动作一致性保证。配置τ>2B也不会绕过严格证书；需要真正恢复完整前瞻时，应关闭bounded_skip。

以基础赢家w作为跳过后的动作，定义相对于完整评分的单步分数遗憾：

\[
R=\max_i(s_i+\delta_i)-(s_w+\delta_w)
\le(2B-m)_+.
\]

对因m>τ而跳过的决策，有R≤(2B-τ)_+。这是原始评分空间里的最坏情况界，不是导航奖励、距离、SR或SPL的界。τ=1时，理论最坏分数遗憾上界为1；本归档中的实际分数遗憾为0，两者不可混同。

阈值选择可以写成开发数据上的约束计算优化：在粗网格中最小化保留查询数，同时要求观察到的动作变化全部保留。该约束是经验性的，未知数据上的零漏选仍须验证。将τ作为论文显式超参数，建议报告τ∈{0.5,0.75,1,2}与无剪枝的计算/动作/导航消融；不要声称这些未运行的阈值已有导航成绩。

该简单门控的价值是可解释、零新增模型训练、与当前有界残差结构一致。不能仅因式子有最坏情况界就宣称新的通用最优算法。
