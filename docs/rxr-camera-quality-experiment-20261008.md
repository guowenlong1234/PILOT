# RxR相机小样本对照（2026-10-08）

用户授权按当前75k权重进行采集和预测质量检查，暂不处理未见场景问题；允许两机资源。仅推理，不更新权重。

固定随机种子20261008，从现存RxR真实密集轨迹按6场景各2条取样，每条在1/3和2/3处取4帧历史，目标为后4/8帧，共48查询。不是实际导航策略候选分布，不据此直接推断导航SR。

四组原生224²渲染：90°/1.25m、90°/0.88m、63°/1.25m、63°/0.88m。相同世界位置、朝向、world_exact_select上下文与11/29/47噪声；每个配对在同一GPU执行。训练机两卡各2场景，测评机专用容器/环境2场景。直接渲染，不使用90°立方体重投影。自动检查光心高度、有限值和权重SHA。

世界模型指标：反归一化CLS余弦、RMSE、标准化patch余弦；另记录直接复制源图CLS相似度，以识别场景本身的难度变化。按场景平均并计算配对变化区间，不把同场景多个噪声当独立样本。

后继预测器：分别输入真实目标图像特征和世界模型预测特征，统计none、建议路点无滑动直线可达率、真实/预测输入输出一致性。几何检查使用同一NavMesh（容差8cm），不等同于教师标签准确率；none不能直接算错误，几何有效不代表语义最优。

预设明显退化提示线：CLS或patch余弦下降0.05，CLS RMSE增加20%，后继路点可达率下降10个百分点。它们仅是本次筛查的操作标准，结合场景一致性与小样本不确定性判断，不是公认性能阈值。

输出：两机各自ETP-R1的`data/logs/rxr_camera_quality_20261008/`。manifest包含固定样本，分片metadata包含软件版本、提交、GPU和权重SHA；RGB压缩数组、编码及预测张量留当地。最初两轮预检分别修复Habitat传感器浮点向量和NavMesh返回向量类型，失败目录保留，不纳入正式统计。

## 完成结果

三个正式分片`formal0/1/2`均completed、退出0，每份16查询；合并48查询×4相机×3噪声=576条世界模型结果，无重复。CWP真实图像192条，预测图像576条。正式源码118b82a。权重未更新。

| 90° / 1.25m | 0.8405 | 0.7324 | 0.5273 | 0.7409 |

RxR相对原相机：整体余弦−0.0612，六场景全部下降，按场景重采样95%区间[-0.0882,-0.0355]；图块余弦−0.0742，区间[-0.0922,-0.0531]；RMSE增加19.09%。前两项超过事先固定的0.05筛查提示线。仅视场改变造成较大退化，不能把两项影响简单相加。

世界模型相对“直接复制源图”仍有收益：原相机+0.0996、RxR+0.0444。收益减少0.0553（约55.5%），配对场景区间[-0.0787,-0.0272]；因此不能称模型完全失效，也不能仅以画面本身变难解释全部下降。

提议可达率分母仅为非none提议；含none的总体“提出且可达”比例，预测输入原相机84.72%、RxR56.25%。预测/真实输入均给出路点时，平均角度差6.17°→10.46°、距离差0.125→0.188m。真实图像输入也有退化，提示后继预测器自身存在相机适配问题；不能把全部变化归因于世界模型。none可能来自视野缩窄，不直接当作错误。3种噪声下重复预测不是144个独立位置样本；这些比例属于描述统计。

**结论：这批样本出现了明显且一致的世界模型质量下降，预测图像→后继路点链路退化更大，建议针对63°/0.88m微调世界模型并适配后继预测器。无需据此从零重训视觉编码器。** 本轮未执行任何适配训练。真实密集路线与策略实际候选分布不同，可达率仅是几何诊断，不能推断完整导航成功率或教师标签准确率。

## 复查与环境

训练机：Python3.10.14；测评机：Python3.11.15。两端PyTorch2.2.2+cu121、CUDA12.1、Transformers4.49.0、Habitat/Habitat-Sim0.3.3。训练机两A6000、测评机3090；各对照都在同一GPU内完成。三份metadata记录相同世界模型、统计文件及CWP SHA、相同采样清单SHA。

运行命令本体：

```bash
# 训练机每卡一个分片，SHARD为0或1
CUDA_VISIBLE_DEVICES=$SHARD bash scripts/rgb_only_optimization_runtime.sh server scripts/rxr_camera_quality.py run --manifest data/logs/rxr_camera_quality_20261008/manifest.json --output data/logs/rxr_camera_quality_20261008/formal$SHARD --shard $SHARD
# 测评机专用容器内
bash scripts/rgb_only_optimization_runtime.sh eval scripts/rxr_camera_quality.py run --manifest data/logs/rxr_camera_quality_20261008/manifest.json --output data/logs/rxr_camera_quality_20261008/formal2 --shard 2
```

三个`.launch.json`保留实际命令和PID；三个`.exit`均0。单样本smoke3两机均completed。汇总脚本`scripts/summarize_rxr_camera_quality.py`校验完整数量和唯一性，正常退出0。笔记本小型汇总在`data/logs/rxr_camera_quality_report_20261008/summary.json`，附三份原始小JSON与版本元数据。仅取回一份代表RGB用于检查相机变化，四列原相机/仅高度/仅视角/RxR、两行源/目标，预览`camera_comparison.png`；没有回传完整图像集或特征张量。
