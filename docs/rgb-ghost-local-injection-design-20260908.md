# RGB-only 注入结构调整建议（2026-09-08）

这是结构分析和下一轮实验设计，尚未实现或运行。依据为三步实验结果及当前全景编码、图更新和图输入组装代码。

## 1. 推荐方向

保留纯观测拓扑图；预测单独处理，在组装导航图输入时，仅对当前有有效预测的ghost施加零初始化、有界的临时修正。第一版不跨决策缓存预测，不改STOP规则、不增加图节点、不启用E24。

预测不能直接与全景编码后的ghost特征相加。两者虽然都是768维，但前者是图像CLS，后者已经融合RGB、深度、方向与全景上下文。优先用冻结全景编码器的“单候选对照编码差值”提供同一空间中的修正依据。

本轮B/C说明冻结可以保护已有能力，但当前接入没有净收益；它没有证明预测没有信息，也没有证明后移注入一定有效。新结构要同时验证影响范围和预测的信息价值。

## 2. 当前结构的真实问题

代码路径：

- `ss_trainer_ETP_R1.py::_run_raenwm_rgb_fusion_prediction`修改候选RGB。
- `_vp_feature_variable`把候选RGB、对应深度和角度，与其他全景方向组成序列。
- `ETP_R1_vilmodel_cmt.py::forward_panorama`进行视觉投影、模态相加、归一化及全景注意力。
- `GraphMap.update_graph`把输出的候选嵌入累计进ghost历史，`get_node_embeds`按观测次数求平均。
- `_nav_gmap_variable`取出这些历史嵌入，交给含语言交互与图注意力的导航模块。

已经有第二次原始全景前向来保护当前真实节点的平均特征，所以不能说预测直接替换了所有真实节点。但仍有三项结构风险：

1. 一个候选的预测会经全景注意力影响其他候选；后者即使没有预测，也可能被间接修改。
2. 观测和预测已经混合后才进入历史平均，无法单独撤回旧预测。
3. 训练时两次全景前向使用不同随机遮挡；零初始化融合算子不等于训练路径与基线一致。新结构应冻结底座并固定eval行为。

这些是代码事实和可检验风险；当前结果不能证明它们各自造成了多少SR下降。

## 3. 推荐的第一版结构

### 3.1 纯观测图保持原样

每一步先对真实全景编码，得到当前节点和所有候选的原始嵌入。图的节点、边、位置、观测次数和历史平均全部按基线更新。

`ghost_embeds`只接收这一路原始候选嵌入。预测不改它，也不把“已经加过修正的特征”再次作为下一次融合的原始输入。

这一路意味着“由真实观测推导出的基线ghost特征”，不意味着已真实看到了ghost目标位置。

### 3.2 将预测转成同一特征空间中的候选专属差值

设完整原始全景输入为O，冻结导航视觉映射为h，冻结全景编码器为E。候选i的原始嵌入为：

```text
e_i = E(O)[i]
```

对于ghost g的预测原始CLS，仅在O的一份独立副本中把候选i的RGB替换为h(pred_raw_g)，其他候选RGB、深度、位置编码、nav_types和掩码全部保留：

```text
e_i_cf = E(O中仅替换候选i的RGB)[i]
d_i = e_i_cf - e_i
```

这称为“单候选对照编码”：只是检查同一个冻结编码器对该候选预测的响应，没有执行环境动作、没有查询第二阶段未来状态，也没有E24评分。

注意：

- 不把多个预测同时放进同一份对照全景，否则d_i仍混入其他预测造成的变化。
- 只取目标候选自己的输出，丢弃对照前向中其他候选以及当前节点的输出。
- 原始输入不得原地修改；对照副本和缓存不能与真实观测数组共享可写引用。
- 这是有意构造的特征对照，不是一幅真实可发生的未来全景；保留的深度仍来自当前观测。它避免新增未来深度预测，但RGB与当前深度的语义适配仍是实验需要检验的限制。
- h来自冻结原始导航基线，E也来自同一基线。C没有提升不等于不能使用h；这里的主要改变是通过E的响应得到同一空间中的差值，以及限制其写入范围。

每个候选需要一次额外的全景编码，可将候选副本组成小批次。它不增加世界模型调用，但会增加全景编码计算和临时内存；实际开销必须测量，不能事先宣称可以忽略。

### 3.3 候选到ghost的聚合必须显式处理

多个当前候选可能映射到同一个ghost，不能把一个预测重复当成多份独立证据。

第一版可以给每个ghost选择一个代表候选：候选位置最接近查询目标均值，若并列则按固定候选索引选择。这个候选用于提取d_i；目标位置、目标朝向及candidate→ghost映射均须与预测记录一致。

原始ghost历史仍保留所有真实观测的平均。代表候选的修正与该历史均值不完全同义，这是局部近似；用下面的相对范数约束限制影响，必要时再对“代表候选”和“匹配观测次数的差值聚合”做独立对照。

### 3.4 只在当前图输入上加入受限修正

令m_g为原始图读出的ghost嵌入，R为小型可训练映射：

```text
u_g = R(d_g)
bounded_u_g = u_g * min(1, rho * ||m_g|| / (||u_g|| + eps))
m_g_input = m_g + bounded_u_g
```

建议R先采用768→128→768的两层、无偏置网络，中间GELU，最后一层权重零初始化。这样约20万参数，且R(0)=0，预测与观测没有差异时不会凭偏置生成额外修改。这是起始设计，不能仅凭参数更少断言泛化更好。

第一版先不加新的学习门，固定有限预算；rho可从0.05开始，在预先固定开发数据上与0.02/0.10作少量比较。它们是待验证起始值，不是已知最优值。

这一约束限制的是特征相对变化，**不保证动作概率只变化同样的百分比**。冻结导航网络仍可能对小特征变化敏感，需要同步测量动作分布变化和路线损失。

`_nav_gmap_variable`先组装原始图输入，再仅修改ghost对应的行。STOP占位和已访问节点的直接输入保持原值；没有有效预测的ghost也保持原值。

### 3.5 第一版预测只活在当前决策

仅使用本步实际获得的预测，不跨步累加预测，也不修改原始历史图。下一步重建临时修正表。

好处是立即排除过期预测和重复累积的影响，关闭注入时原始历史可以直接恢复。代价是历史ghost本步没有新预测时只使用原始观测特征，不能继续享受旧预测信息。

若这一版有效，再单独增加短缓存：保存未经过R的冻结差值或两路嵌入，以及source/target位姿、目标朝向、ghost映射版本和生成步数；目标均值改变、ghost被访问/消费、episode切换或预测失效时清除。缓存不能只用ghost ID，不能把经过旧参数R加工后的特征永久保存后继续训练R，也不能无条件平均不同目标视角的预测。

## 4. “只改ghost”不能保证STOP不变

目前图导航会让所有图节点与指令交互，再计算动作分数。即使STOP和真实节点的直接输入没动，ghost变化仍会通过图注意力改变STOP输出和其他方向的分数。

因此，本方案限制的是预测进入图的入口及历史污染，不是将决策影响完全隔离。不要承诺STOP概率不变，也不要第一版同时手工修改停止阈值。

保留纯观测图还使同一状态下的基线前向变得容易：可以取得纯观测的动作分布，与增强分布进行比较。若需要进一步保护基线，可在训练场景、基线与教师动作一致的状态上增加适度的分布保持约束；对基线已经错误的状态不应强制模仿。这个约束作为后续独立变量加入，避免一次改动太多。

## 5. 门控应该学习什么

当前B/C门均值接近1，不能继续把现有余弦提示视作可靠性标签。同位置预测准确与否，以及这份预测对指令决策有没有帮助，是两种不同问题。

先验证局部修正有信息价值，再考虑加门：

- 输入可包含原始/对照候选嵌入、距离、转角和上下文质量；如果需要指令条件，可以使用冻结语言特征，或纯观测导航分支的跨模态表示。
- 标签优先来自训练场景的预测误差或导航作用，不使用验证集成功结果训练。
- 导航作用的一种诊断标签：固定同一状态和教师动作a*，只探测一个ghost的小幅修正，比较教师动作的对数概率变化。正变化表示在这个局部探测下有帮助；多ghost同时融合存在交互，因此这不是最终效用真值或独立收益的保证。
- 使用真实未来图像时，它只能是训练标签或离线诊断信息，正式策略不能获取这些真值。

新门必须报告校准与分组结果，不能只报告均值或把sigmoid输出直接称为准确率。

## 6. 训练与验证顺序

新结构从原始base_iter14200开始，冻结导航底座与世界模型，固定eval行为，单独训练R。旧B/C adapter不能直接作为这个不同语义接口的初始化；旧网络权重需要单独的版本合同，禁止靠宽松load忽略缺层来混用。

冻结E与h可以作为固定输入生成器，不追踪其参数梯度；R之后的图导航必须保留对输入的梯度，不能把整个导航前向放在no_grad里。无有效预测的rollout也要有正确的零梯度处理，沿用已有冻结训练的同步与审计经验。

先完成结构验收：

1. 同一观测、指令、图状态下，零初始化或禁用注入的动作logits与基线一致（按实际精度设容差）；不承诺不同完整仿真运行的路线逐位确定。
2. 原始图的节点/ghost特征和观测次数不被预测分支改写。
3. 修改一个预测时，其他候选的直接原始嵌入不变；图导航后的全局分数变化属于允许的联动。
4. 无预测、预测非法、重复candidate→ghost、环境暂停/episode切换均能正确回退与清理。
5. R有真实梯度并更新，冻结底座逐张量不变，注入相对范数不超过预算。

然后做少量相同预算对照：

| 方案 | 检验内容 |
|---|---|
| 冻结原始基线 | 基准 |
| 当前B式早期RGB融合 | 与新的注入位置比较；需统一有效干预预算，不能仅沿用旧alpha数值 |
| 新结构、仅观测同容量适配器 | 额外参数本身能否提高表现；输入原始候选特征，参数量和预算匹配 |
| 新结构、正常预测 | 预测内容有没有超出容量对照的价值 |
| 同结构、同位姿真实未来CLS | 仅作离线/训练诊断上界，判断接口能否使用有用的未来视觉 |

真值必须对应真实可渲染、同一位置和朝向；ghost估计位置不可达或需要投影时记录误差，不能把别的位置图像当作精确真值。真值也需要合理训练/适配，并检查预算是否过紧；直接替换进去没有收益，不足以否定未来视觉价值。

先在训练场景和预留开发场景做预测质量、单步决策与小规模导航筛查。只有接口确实能利用信息，才进行下一轮完整训练和预定完整评测。不给val_unseen反复追加大量阈值搜索；本轮已经使用过该集合，后续结果需明确选择偏差。

## 7. 最小代码改动范围

- `ss_trainer_ETP_R1.py`：拆开预测与原地RGB融合，先纯观测全景编码/更新图；生成单候选对照差值，在图输入组装后临时施加修正。
- `nwm/`新增独立的ghost嵌入修正模块及配置合同；保留现有旧RGB融合模式，便于复现对照。
- `models/graph_utils.py`：第一版不改变原始ghost平均算法，不必新增长期预测缓存；后续缓存版本必须单独实现失效规则。
- 现有`forward_panorama`可复用；图导航的节点集合、位置关系、语言交互和动作头保持基线定义。
- 加入原始图不变、零初始化一致、候选隔离、映射与梯度测试；验收与实验在目标机器的专用工程环境执行。

这套方案优先改变“预测如何进入决策”，不会自动解决世界模型预测质量不足。是否超过基线只能由上述对照确认。
