# SOTA 技术缺口图谱

> 证据截点：2026-08-28 11:00（Asia/Shanghai）。本文只判断“现在有什么证据可以支持什么强度的论断”，不把设计目标、训练中趋势或预期优于基线写成既成结果。外部文献用于界定现有技术范围；项目结果只取自仓库材料、完整结果 JSON 和只读运行状态。

## 证据状态定义

- **已验证事实**：有完整代码链路、测试/数值验收或完整 split 结果文件支持。
- **已有但不理想结果**：实验确有结果，但性能未稳定超过同口径基线，或比较中存在不可消除的配置混杂。
- **正在运行**：进程与产物仍在增长，只能报告进度和已完成 checkpoint，不能报告最终最优结果。
- **计划实验**：已有配置、脚本或设计，但正式长训练/完整评测尚未启动。

## 当前结果的证据边界

### 1. 可以作为论文结果的旧 ETP-R1 证据

旧 CLIP 链路的四个发布 checkpoint 已在完整 `val_unseen` 上复现，可支持“ETP-R1 的闭环 GRPO 相对其对应 SFT 有效”这一有限结论。它不能支持“RAE/DINOv2、native CLS、E24 或新冻结式 GRPO 已优于旧 ETP-R1”，因为这些模块不在旧 checkpoint 中。

### 2. 当前原生 CLS + E24 中间结果

同口径现代 RAE/DINOv2 基座 `iter14200` 的完整 R2R `val_unseen` 为：NE `4.1232`、OSR `68.1349%`、SR `63.7303%`、SPL `55.6054%`。截至证据截点，联合训练已完成的 12 个 checkpoint 中：

- SR 最高的是 `iter2000`：SR `63.2953%`，但 SPL 只有 `53.5741%`；
- SPL 最高的是 `iter1200`：SPL `55.1929%`，SR `62.4796%`；
- 最新已完成的 `iter2400`：SR `60.3589%`、SPL `51.8745%`；
- `iter2600` 尚在完整评测，训练约到 `iter2800/10000`。

所以，目前任何已完成中间点都没有同时超过基座的 SR 和 SPL。正确表述是“正式训练与逐 checkpoint 全量评测正在进行，早期点尚未显示稳定增益”，不能写“已经提升”或根据未来预期提前设计成正结果。

### 3. 评测口径限制

R2R-CE test 服务器已经冻结；新模型应以完整 1,839 episode `val_unseen` 为主，不得把验证集数字填进 Test Unseen。现代配置默认 `teleport`，旧论文发布评测显式使用 `control`；跨代比较必须重跑相同控制器。已有新链路 GRPO `iter750` 的结果也因该口径差异只能视为内部参考，不能直接进入最终主表。

## Gap Summary

项目最可靠的既有贡献仍是：在 ETPNav 拓扑规划骨架上，用跨 R2R/RxR 的大规模联合预训练和闭环在线 GRPO形成完整训练体系，并且旧发布 checkpoint 的完整验证集结果可以复现。新的 RAE/DINOv2、native CLS 世界模型和 E24 前瞻链路目前提供了很强的工程与数值正确性证据，却尚未形成同等强度的导航性能证据。

因此论文重写时应把主张分成两层：第一层是已验证的 ETP-R1 训练范式和旧结果；第二层是正在研究的表征世界模型前瞻扩展。若要把第二层升级成核心方法贡献，真正需要补的是严格消融、同口径性能、统计稳定性和预测—决策因果分析。宽泛的“首次世界模型用于 VLN-CE”被 NavMorph 覆盖；宽泛的“首次 GRPO 用于 VLN”也被 NavGRPO 覆盖。相对可守的新颖性是：**原生 CLS+patch 世界模型如何与在线拓扑 ghost 对齐、以冻结前瞻模块约束组相对策略优化，并在连续控制环境中闭环验证**。即便如此，也必须等正式实验完成后再决定是否能写“有效”。

## 建议补充实验（按优先级）

### P0：形成可发表主张前必须完成

1. **完成当前 R2R 10,000 次训练和全部 50 个 checkpoint 的完整评测**。按预先固定的 `SR+SPL → SPL → SR → iteration` 规则选点；同时公开全曲线，避免只展示幸运 checkpoint。
2. **同起点、同预算的核心消融**：`base`、`DINO/RAE only`、`RGB-NWM only`、`E24-only`、`RGB-NWM+E24`。所有组固定预训练基座、`iter14200` 起点、DAgger 时间轴、环境数、总轨迹数、随机种子、控制器和 checkpoint 选择规则。
3. **统一评测语义**：最终新模型、RAE 基座、旧 ETP-R1 SFT/GRPO 均至少以 `control` 完整重跑 R2R `val_unseen`；`teleport` 结果只能放内部分析或单独表格。
4. **统计不确定性**：至少 3 个训练种子；若成本受限，也应对完整 episode 做配对 bootstrap，报告 SR/SPL 差值的 95% 置信区间，并明确它不能替代训练种子方差。
5. **停止错误与 GRPO 概率语义复核**：已有采样统计显示达到最大轨迹长度造成的强制停止并不罕见。正式 GRPO 前必须修正或量化其对 old/current/reference 概率比、reward 和最终指标的影响。

### P1：支撑机制解释和跨任务结论

1. **预测质量—决策收益联动分析**：报告 q0/q1 预测 CLS 与真实未来 CLS 的余弦/误差，按误差分桶统计 gate、E24 delta、action flip、SR/SPL 变化；区分“修正错误动作”和“破坏正确动作”。
2. **Top-5 与上下文消融**：Top-K={1,3,5,10}、context={1,2,4}、无 CWP/Oracle-CWP、只 CLS/只 patch/完整 257 token；同时报告 future-valid rate、延迟和显存。
3. **完成 R2R native-CLS/E24 冻结式 GRPO**：从严格选出的 joint SFT 单一起点启动，比较 SFT 与 GRPO；世界模型、两个 adapter、E24 均保持冻结，并验证 current/reference 使用同一冻结 residual。
4. **完成 RxR 普通 SFT→joint SFT→GRPO**：正式跑完 30,000/10,000 次和 11,006 episode 完整评测，按预先固定的 SDTW→NDTW→SPL→SR 选优，不能从 R2R 结果外推。
5. **数据贡献消融**：等预算比较 R2R-only、R2R+RxR、+Prevalent、+Gemini；去掉文本/图任务 embedding 和图文再融合头，补充指令重复率、幻觉率和人工质量抽检。

### P2：增强 SOTA 竞争力与审稿说服力

1. **鲁棒性评测**：参考 NavGRPO 的扰动设置，加入早期动作扰动、视觉噪声、定位/朝向误差和恢复能力，验证闭环 RFT 是否真的提升分布偏移鲁棒性。
2. **计算代价**：报告 DINO、q0/q1 NWM、CWP、E24 各自耗时，端到端每步延迟、GPU 显存和吞吐；与无前瞻基座比较性能—成本曲线。
3. **失败案例与校准**：按上下文不足、CWP-none、NWM 行失败、低一致度、STOP、Top-5 外教师动作分类，展示前瞻何时应回退。
4. **泛化边界**：除 R2R/RxR `val_unseen` 外，在许可和数据可用范围内增加跨场景/跨语言分组结果，避免只报告总体均值掩盖语言或路径长度差异。
