# Contribution Reviewer 结构化审稿意见

## Summary

### 总体判断

**当前结论：不建议以现状送审英文机器人/具身智能期刊。** 这不是因为稿件完全没有可发表想法，而是因为“可守的新颖性”很窄，而决定其学术价值的实验仍大面积缺失。当前稿件更接近一份边界意识较好的研究设计与工程验证报告，尚不是一篇完成了核心科学论证的期刊论文。

本稿相对 ETPNav、ETP-R1、NavMorph 与 NavGRPO 后，仍可能成立的核心增量是：**把冻结世界模型生成的原生 CLS+patch 未来表征逐候选对齐到在线拓扑 ghost，并通过 Top-5、STOP 隔离、有界残差和逐行回退限制其可干预范围，再把该前视分支限定为 SFT 学习、GRPO 冻结。** 这一定义比“世界模型用于 VLN-CE”“多步前视”“GRPO 用于 VLN”更准确，也基本遵守了 `confirmed_contribution.md` 的主张边界。

但该增量目前主要表现为系统组合和训练契约，而不是已经证明的新能力或新认识。NavMorph 已覆盖连续环境 VLN 中的潜在空间世界模型、未来视觉表征、前视动作规划、R2R-CE/RxR-CE 验证以及 1--5 步预测消融；ETP-R1 已覆盖 ETPNav 骨架、联合预训练、在线 SFT 与闭环 GRPO；NavGRPO 已覆盖组相对优化、轨迹多样性和扰动鲁棒性。因此，本稿能否达到期刊送审价值，取决于它能否证明以下至少一项，而不是只证明代码按设计运行：

1. 候选级受约束前视在同口径、多种子条件下带来稳定且有实际意义的导航收益；
2. 相比 NavMorph 式整体潜在前视，候选级对齐在效果、可靠性、可解释性或成本上有明确优势；
3. 即使平均性能不提升，也形成可信、可复用的机制结论，例如预测误差、候选覆盖、策略 margin 与动作修正/伤害之间的定量边界。

当前三项均未建立。正文第 4 节主结果、模块消融、oracle/predicted q1、多步前视、动作翻转、效率、RxR 和新 GRPO 都还是占位或计划；已经完成的早期结果尚未同时超过基座，future-valid 约为 46.6%--49.6%，动作翻转率仅约 0.17%--0.29%。这些数字支持“链路可运行”，但反而强化了“昂贵模块接近不改变策略”的显著性疑问。

### 送审价值判断

| 判断维度 | 当前状态 | 审稿判断 |
|---|---|---|
| 新颖性 | 有窄而可守的候选级约束增量，但与 NavMorph 的方法重叠尚未充分展开 | **边缘，需直接对照后才能判断** |
| 技术贡献 | 工程契约完整，科学机制和不可替代性未证明 | **不足** |
| 性能证据 | R2R 早期点未稳定胜出；RxR、新 GRPO、多步、严格消融、多种子缺失 | **不具备送审条件** |
| 泛化证据 | 仅计划覆盖同一仿真生态中的 R2R/RxR；单一 RAE-NWM | **不足** |
| 机器人意义 | 尚无传感噪声、执行扰动、真实机器人或实时性证据 | **对综合机器人期刊偏弱** |
| 诚实性与边界 | 主动承认 NavMorph/ETP-R1/NavGRPO 先行工作，不宣称 SOTA 或普遍提升 | **较强** |

若最终得到稳定正收益并完成同口径对照，本工作可能适合贡献集中的具身智能或机器人学习期刊/Letters。若目标是更强调完整机器人系统与广泛影响的 Transactions 类期刊，仅有仿真指标和工程约束通常仍不够，需要更强的鲁棒性、实时性或实体部署证据。若最终收益接近零，则应转为机制/负结果研究，并证明该分析能给出超越本系统的可复用结论；否则不宜把它包装成新方法论文。

## Strengths

1. **新颖性边界整体较克制。** 引言第 37、41 段和相关工作第 58、62 段明确承认 NavMorph 已将世界模型用于 VLN-CE、ETP-R1 与 NavGRPO 已研究 GRPO，避免了明显失实的“首次”表述。建议保留这种写法。

2. **主张与证据的区分较诚实。** 方法第 99、123 段明确说明实现一致性和动作范围约束不等于导航性能提升；实验第 176 段及结论第 290 段也没有把训练中趋势改写成既成结果。这符合 `confirmed_contribution.md` 的证据边界。

3. **候选级干预范围定义清楚。** 方法第 68--83、107--123 段把 Top-5 ghost、STOP 隔离、非 Top-K 保持、残差限幅和失败回退写成了可检查的系统契约。这比笼统地说“利用未来特征增强策略”更容易复现和审计。

4. **实验问题方向正确。** 第 170--275 段计划使用逐级消融、无 q1/oracle/predicted q1、多步视野、动作修正/伤害、误差分桶和开销分析。若严格完成，这套证据有机会把论文从“模块堆叠”提升为机制研究。

5. **负结果出口被提前保留。** 讨论第 280--286 段承认低翻转率、误差累积、冻结造成的适应性限制和部署成本。这降低了结果不符合预期时的过度解读风险。

## CRITICAL

### C1. 核心性能主张没有证据，稿件尚不构成完整论文

- **触发位置：** 摘要第 26 行；实验第 149--168、174--275 行；讨论第 286 行；结论第 290 行。
- **问题：** 所有能验证核心贡献的结果仍是占位符：R2R/RxR 的 SFT 与 GRPO、逐级模块消融、oracle/predicted q1、1/2/3 步、动作翻转、预测质量和效率均未完成。当前唯一可比较的新链路数字是 R2R 基座 SR 63.7303、SPL 55.6054；早期主动前视 checkpoint 尚未同时超过它。系统加载、数值一致性、梯度边界和 checkpoint 恢复只证明工程正确性，不证明方法有效、重要或值得发表。
- **风险：** 直接送审会在摘要和结果页即被判为未完成研究；即使删除占位符，只保留工程测试，也不足以支撑方法论文。
- **可执行修复：** 完成同控制器、同选点规则、同预算的 R2R 与 RxR 全量 SFT/GRPO；至少 3 个训练种子，报告均值、标准差和配对 bootstrap 95% 置信区间；回填全部表格和图；在摘要中给出最终效应量及边界。若无法完成 RxR 或新 GRPO，应删除相应贡献承诺并缩小论文范围，而不是继续保留计划式表述。

### C2. 相对 NavMorph 的重叠被低估，当前差异尚不足以自动构成期刊级新颖性

- **触发位置：** 引言第 37--47 行；相关工作第 56--58 行；方法第 93--123 行；实验第 222--244 行。
- **问题：** 正文把 NavMorph 概括为“世界模型可用于 VLN-CE”，但其实际覆盖范围更接近本稿：它在 VLN-CE 中学习动作条件的潜在状态转移，预测未来视觉 embedding 用于前视动作规划，在 ETPNav 等基础模型上验证，并在 R2R-CE/RxR-CE 上报告结果；补充实验还比较了 1--5 个预测步。因而，“潜在未来表征”“连续环境前视”“多步权衡”“在 ETPNav 类策略上增益”都不能单独作为本稿新意。
- **风险：** 审稿人会认为本文只是把 NavMorph 的整体潜在前视改造成 raw CLS+patch、Top-5 ghost 和残差头，属于接口替换或保守工程变体。尤其第 47 行把 1/2/3 步分析列为贡献，会被 NavMorph 已有 1--5 步消融直接削弱。
- **可执行修复：** 在相关工作后增加“Closest-method delta”表，逐项比较 NavMorph 与本文的基础策略、未来表示、候选条件、是否逐 ghost、是否查询未来观测、前视步数、干预位置、STOP/非 Top-K 行为、在线适应、训练/推理更新、复杂度和验证任务。随后把贡献句改为可检验的差异，例如“candidate-conditioned, intervention-bounded residual lookahead”，而不是“多步未来表征”。最重要的是，在相同 ETPNav/ETP-R1 基座、控制器、视觉输入和训练预算下直接复现或适配 NavMorph；若不能运行，应至少实现最接近的整体潜在前视对照并说明差异。没有这一对照，不能声称候选级设计优于已有世界模型路线。

### C3. 相对作者已有 ETP-R1 的实质扩展量未被正式证明

- **触发位置：** 引言第 35、41、43--47 行；方法第 81--137 行；主结果第 176--199 行。
- **问题：** 本稿继承 ETP-R1 的拓扑骨架、联合预训练、在线 SFT 和 GRPO。当前新增内容主要是 RAE/DINOv2/NWM、CLS adapter、E24 及冻结契约。第 46 行把“可复现训练契约”列为独立贡献，但 SFT→GRPO 阶段化训练本身已经属于 ETP-R1；仅冻结新增分支可能被视为常规稳定化选择。正文没有一张版本差异表说明旧 ETP-R1 的哪些模块、数据、结果和结论被复用，哪些是新稿独有，也没有量化新增实验和新结论。
- **风险：** 对期刊稿或已有预印本扩展，编辑可能质疑实质新增技术信息不足、旧结果与新结果混用、贡献重复计算。
- **可执行修复：** 在引言末或补充材料加入 ETP-R1→本文的版本差异表，至少列出架构、视觉表征、世界模型、候选打分、损失、可训练参数、GRPO 更新集合、数据、控制器、checkpoint 起点、实验和结论；旧结果与新结果分表呈现。把第 46 行改为更窄的“前视残差在 SFT 学习、GRPO 冻结的分布一致性设计”，并用冻结/联合更新/无前视三组实验验证，而不是把工程测试本身当作科学贡献。

### C4. 当前观测到的干预极稀疏，显著性和成本收益面临根本质疑

- **触发位置：** 实验第 244、246--275 行；讨论第 280、286 行；`sota_gap_map.md` 的当前结果边界。
- **问题：** future-valid 只有约 46.6%--49.6%，动作翻转率约 0.17%--0.29%，且早期 checkpoint 尚未稳定超过基座。一个需要 DINO、q0 NWM、CWP、q1 NWM 和 E24 的链路若绝大多数时间不改变动作，审稿人会问其是否只是高成本近似恒等映射。Top-5 与残差上界只限制最坏干预范围，并不等于有效、校准或有实际价值。
- **风险：** 即使最终出现小幅单点增益，也可能落在训练方差、checkpoint 挑选或控制器差异内，无法证明复杂链路必要。
- **可执行修复：** 报告 action flip 的逐动作与逐 episode 分母、覆盖率、策略 margin、残差幅度、修正/伤害数及置信区间；加入参数匹配的“仅用当前/历史特征的残差头”、shuffled future、mean/random future、zero-delta、E24-only 和 oracle future 对照。用单位额外延迟/显存带来的 SR/SPL 改善画 Pareto 曲线。若净修正、平均性能或成本收益不成立，应停止以“有效方法”定位，转为受约束前视的失败边界/诊断研究，并相应修改题目、摘要和贡献条目。

### M6. “受约束”容易被误读为安全或鲁棒保证，但当前只有作用域限制

- **问题：** Top-K、STOP 隔离和残差上界保证的是哪些 logits 可以变化、变化幅度多大，不保证排序不恶化、轨迹不变差或系统安全。正文第 123 行承认这一点，但标题和摘要的“受约束”仍可能诱发更强解读。

### M7. 泛化主张目前没有相应证据

- **触发位置：** 摘要与关键词的潜在英文改写；实验第 141--145 行；讨论第 286 行；`confirmed_contribution.md` 的 Claims to soften or avoid。

- **可执行修复：** 明确把结论限定为指定 R2R-CE/RxR-CE 配置；按语言、路径长度、场景类型分组报告 RxR/R2R；如要使用 generalizable/robust，至少增加视觉噪声、位姿/朝向误差、早期动作扰动和另一世界模型或表征预测器。没有这些结果时，英文稿避免 general、robust、transferable、significant。
