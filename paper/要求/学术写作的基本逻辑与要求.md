# 学术写作的基本逻辑与要求

> 整理日期：2026-09-05  
> 依据：本目录中的 13 张图片。本文按写作逻辑重新组织、合并重复内容，并非逐字转录。部分图片边缘和底部文字被截断，仅采用可辨认内容。  
> 来源区分：第 1—7 节为图片内容的归纳；第 8—10 节为整理者补充；第 11 节为两者合并后的检查清单。图片中的模型名称和宣传标题不作为学术依据，也不构成写作时长或质量的保证。  
> 适用范围：以研究型论文为主。具体章节名称、字数、引文和排版要求，以目标期刊、会议或学校规范为准。

## 1. 核心逻辑：让问题、方法、证据和贡献连起来

学术写作首先要建立一条读者能够检查的论证链：

**研究背景 → 已有知识 → 尚未解决的问题 → 研究必要性 → 本文的研究问题与目标 → 研究方法 → 实际发现 → 贡献及其边界。**

这条链条中，每一步都要有明确作用：

| 环节 | 需要回答的问题 | 基本要求 |
| --- | --- | --- |
| 研究背景 | 这个问题发生在什么情境中？为什么值得关注？ | 只保留与核心问题有关的事实和概念 |
| 已有知识 | 前人已经研究了什么、解决了什么？ | 有可追溯文献，准确概括共识和分歧 |
| 现有不足 | 还有什么没有得到充分回答？ | 从具体文献及其边界推导，不能凭空制造 |
| 研究必要性 | 这个不足会带来什么影响？ | 说明具体的理论、方法或实践价值 |
| 问题与目标 | 本文到底要回答什么、完成什么？ | 具体、范围清楚、能够由研究设计回答 |
| 方法 | 为什么用这些方法，如何实施？ | 与研究问题、数据和对象相匹配 |
| 发现 | 研究实际得到了什么？ | 依据真实结果，不能把计划写成发现 |
| 贡献与边界 | 相比已有知识增加了什么？适用于哪里？ | 有证据支撑，不超出研究覆盖范围 |

**基本判断标准：读者应当能沿着“为什么研究—如何研究—凭什么得出结论”理解全文。**

## 2. 动笔前：先准备研究信息

图片强调，在撰写任何章节之前，应先提供已经确定的研究信息。没有的信息要明确标记，不能让写作者或辅助工具自行补造。

建议先建立一张研究信息卡：

```text
研究主题：
所属领域：
核心研究问题：
研究目标：
研究对象、样本或场景：
已确定的研究方法：
数据、实验材料或案例来源：
已经得到的核心发现：
已有文献及可靠参考资料：
```

其中，“核心发现”如果尚未获得，应写“尚未完成实验”或“结果待验证”。不能为了让摘要完整而补上虚构的结果。

动笔前至少检查三种对应关系：

1. 研究问题是否确实来自前面识别出的不足？
2. 研究目标是否对应研究问题？
3. 现有方法和数据是否足以回答这些问题？

## 3. 摘要：用最少文字交代完整研究

摘要应概括研究问题、方法、核心发现和贡献，让读者在不阅读全文的情况下了解研究的主要内容。

### 3.1 推荐顺序

**必要背景 → 问题或不足 → 研究目标 → 对象、数据与方法 → 主要结果 → 贡献或启示。**

写作前先确认六项信息：背景或问题、目的、对象或材料、方法、结果、贡献。缺少关键项时，应先补充研究信息或保留明确的草稿标记。

### 3.2 基本要求

- 背景简短，只保留理解问题所必需的信息。
- 明确指出本文研究的具体问题。
- 说明研究采用的对象、数据和方法。
- 结果必须来自真实研究，不能虚构数值、统计显著性或实验结论。
- 贡献应由结果支持，避免“具有重要意义”“取得良好效果”等空泛评价。
- 不重复引言中的大量背景内容。
- 语言准确、紧凑、连贯，符合目标刊物的摘要格式。

### 3.3 可填写骨架

> 在【具体研究情境】中，【具体问题】仍受到【已有证据支持的限制】。为研究这一问题，本文针对【对象或数据】，采用【方法及核心思路】。结果表明【已经验证的主要发现】。这些发现为【具体理论、方法或实践问题】提供了【证据支持的贡献】。

骨架用于检查信息是否齐全，不要求每篇摘要机械套用同样句式。没有结果时，结果栏只能作为草稿占位，不能作为完成版结论。

## 4. 引言：逐步说明为什么需要这项研究

引言的主线是：

**为什么值得关注 → 已经知道什么 → 仍然不知道什么 → 为什么这个不足值得解决 → 本文具体做什么。**

下面五部分是逻辑功能，可以根据篇幅合并或拆分，不必机械设置五个小标题。

### 4.1 研究背景：把读者带到具体问题上

交代基本研究或应用情境、与问题直接相关的核心概念，以及理论、现实或方法上的意义。

要求：

- 优先采用已有资料中的事实、数据和研究发现。
- 不铺陈整个领域的发展史，不写与后文无关的百科式介绍。
- 避免“随着社会不断发展”“近年来受到广泛关注”等缺少信息的开头。
- 不编造趋势、数据或研究结论。
- 背景段结束后，应能用一句话说清它把读者引向了什么问题。

### 4.2 研究现状：概括进展，为不足做铺垫

引言中的研究现状只需概括与核心问题直接相关的进展。详细的理论、方法和文献比较通常放在文献综述或相关工作中。

可以按研究主题、理论观点、技术路径或主要发现分类，并回答：

1. 现有研究主要集中在哪些方向？
2. 哪些认识已经比较明确？
3. 不同研究是否存在结论差异？
4. 哪些问题仍未得到充分解释？

每个概括都应能够追溯到文献或可靠材料。存在分歧时，要如实呈现，不能强行统一结论；研究结果不同，也不自动意味着其中某一项研究不足。

### 4.3 研究空白与现有不足：从证据中推导

研究空白（Research Gap）指已有知识尚未充分回答、而且值得进一步研究的问题。

应依次说明：

1. 已有研究具体做了什么？
2. 哪些问题已经得到较充分回答？
3. 哪些问题尚未回答？
4. 为什么已有研究的设计、数据或方法还不足以回答？
5. 这个不足带来什么理论、方法或实践影响？
6. 本研究为什么有可能推进这一问题？

可能的切入点包括：理论解释不足、研究对象或场景覆盖不足、数据或时间范围限制、方法局限、关键变量或机制缺失、结论矛盾，以及新现象无法被现有解释覆盖。

这些只是检查方向，不能当作自动生成“创新点”的清单。每一项都必须回到具体文献。

**推荐表达顺序：已有研究 → 可核实的局限 → 尚未解决的问题 → 进一步研究的必要性。**

避免只写“相关研究较少”“现有研究仍然不足”。如果材料不足以证明存在明确空白，应直接承认证据不足，继续核查文献。

### 4.4 研究问题：清楚界定本文要回答什么

区分两层：

- **核心研究问题（Research Problem）**：研究整体要处理的关键难题。
- **具体研究问句（Research Questions）**：把关键难题拆成能够通过方法、数据或分析回答的问题。

要求具体、可研究、范围明确，能够对应后续研究设计。不要仅把一个宽泛目标改成疑问句，也不要提出研究设计无法回答的问题。

可使用以下结构检查：

```text
核心研究问题：

具体问题 1：
对应的研究方法、数据或分析：

具体问题 2：
对应的研究方法、数据或分析：

这些问题如何回应前文的研究不足：
```

### 4.5 研究目标、范围与贡献：说明本文实际承担什么

引言结尾应说明核心目标、对象与范围、总体思路，以及由研究设计和实际结果支持的贡献。

- 每项目标应对应一个研究问题或具体研究任务。
- 说明研究边界，避免让读者误以为本文覆盖所有对象和场景。
- 贡献必须建立在实际工作和结果上。
- 避免无法证明的“首次”“填补空白”“重大突破”。
- 研究未完成时，应使用“旨在”“计划考察”“设计用于”等表述，不能提前宣布成果。
- 论文结构介绍仅在目标刊物或论文类型确有需要时加入。

## 5. 文献综述与相关工作：建立研究定位

文献综述的任务包括建立理论和方法基础、比较已有研究、识别其边界，并说明本文处于什么位置。

推荐主线：

**研究主题为什么成立 → 已有哪些解释和研究方向 → 有什么共识与分歧 → 可以借鉴哪些方法 → 还有什么问题无法回答 → 本文如何定位。**

### 5.1 先论证研究主题的合理性

可从以下角度选择与研究真正相关的内容：

| 角度 | 要说明的内容 |
| --- | --- |
| 理论 | 当前理论能解释什么，还有哪些现象解释不足？ |
| 实证 | 哪些发现需要进一步验证、比较或扩展，是否存在矛盾？ |
| 方法 | 现有方法有哪些限制，新数据或设计能否推进问题？ |
| 实践 | 这个问题具体影响什么应用、行为或决策？ |

最终应形成“已有知识 → 未解决的问题 → 为什么重要 → 为什么需要进一步研究”的论证，避免仅宣称“具有理论意义和现实意义”。

### 5.2 先分类，再比较，最后形成综合论述

分类可以依据理论流派、研究主题、对象、方法、结论或发展阶段。选择最能服务当前问题的方式，不要机械用完所有分类维度。

对每类文献回答：研究了什么、采用什么理论或方法、得出什么结论、与其他研究有何异同、存在什么限制、对本文有什么启发。

写作时，让研究问题和观点组织段落。避免全文变成“A 做了什么，B 做了什么，C 做了什么”的逐篇流水账。

可采用这样的段落骨架：

> 围绕【问题】，已有研究形成了【若干方向】。其中一类通过【共同思路】处理【具体困难】，并在【已验证条件】下取得【有出处的发现】；另一类关注【不同侧面】。两类研究在【比较维度】上存在差异，但在【与本文有关的条件】下仍有【有证据支持的不足】。因此，本文考察【具体问题】。

### 5.3 借鉴方法时，说明选择与调整的理由

对借鉴或调整的方法，至少检查七项：

1. **来源**：方法来自什么研究传统或已有工作？
2. **典型用途**：通常用于解决什么问题？
3. **适配理由**：为什么适合本文的问题、数据或对象？
4. **前人证据**：哪些研究已经用它处理类似问题？
5. **优势**：它能提供什么具体能力？
6. **局限**：有哪些已知限制？
7. **调整**：本文针对新对象或情境做了什么改动？

重点是“为什么选择 → 为什么适合 → 如何调整 → 有什么局限”，不能停留在方法定义。

### 5.4 引言与文献综述的分工

| 内容 | 引言 | 文献综述或相关工作 |
| --- | --- | --- |
| 主要任务 | 引出问题，说明研究必要性与本文工作 | 比较研究关系，建立理论、方法及研究定位 |
| 研究现状 | 概括关键进展 | 分类别展开比较 |
| 文献细节 | 只保留支撑主线的必要信息 | 说明假设、方法、结论和适用条件 |
| 现有不足 | 提炼直接驱动本文的问题 | 给出更充分的比较依据 |

同一文献可以出现在两处，但应承担不同的论证功能，避免重复相同内容。

## 6. 学术表达：具体、准确、有段落功能

- 每段应有明确任务，段落之间应形成解释、因果、比较或递进关系。
- 删除空泛表达和无信息量的评价词。
- 避免重复句式和概念堆叠。
- 谨慎使用“重要”“显著”“新颖”以及对应英文评价词；评价应有证据。
- 创新性、贡献和研究意义要具体说明，不能仅靠形容词成立。
- 保持连续、自然的学术论述，不把正文写成未经组织的资料清单。

## 7. 事实真实性与证据边界

图片明确要求检查数据、文献、研究发现和创新性声明是否有支持，并区分直接证据与合理解释。

| 信息类型 | 写作要求 |
| --- | --- |
| 已有资料直接支持的观点 | 给出来源，并保留原研究的对象和条件 |
| 基于资料的合理解释 | 明确是解释或推断，不写成已经证实的事实 |
| 本研究的问题、目标和贡献 | 区分准备开展的任务与已经完成的工作 |

提交前检查：是否出现未提供资料支持的数据、不存在的研究或文献、夸大的发现；研究空白是否由文献推导；问题能否被设计回答；目标是否与问题对应。

## 8. 补充见解：用“主张—证据对应表”约束全文

> 本节为整理者补充，尤其适用于算法、机器学习和工程实验论文。

写作中常见的困难是：某句话看起来合理，但现有实验并不能支持它。建议在润色之前，先给每条核心主张找到对应证据。

| 主张类型 | 需要怎样的证据 | 常见越界 |
| --- | --- | --- |
| 方法整体更有效 | 与有代表性的基线在可比条件下评测 | 只选弱基线，或忽略训练资源和数据差异 |
| 某个组件有作用 | 控制其他条件，移除、替换或改变该组件 | 仅凭完整系统的表现解释组件贡献 |
| 改善来自某种机制 | 有针对性的干预、对照或机制分析 | 把总体指标提升直接当成机制证明 |
| 泛化能力更好 | 在明确区分的未见数据、环境或分布上验证 | 只用训练分布内的结果宣称广泛泛化 |
| 更高效 | 在可比条件下测量延迟、显存、算力或其他相关成本 | 只看参数数量，忽略实际运行成本 |
| 更稳定 | 重复实验、波动统计或相关扰动测试 | 用一次实验宣称稳定 |

移除组件的实验通常称为“消融实验”。它可以提供组件是否有贡献的证据，但如果同时改变了参数量、训练预算或其他设置，就仍然需要谨慎解释。

建议维护：

```text
拟写入论文的主张：
对应的研究问题：
支持它的文献、实验或推导：
证据覆盖的条件：
尚未排除的其他解释：
允许采用的结论表述：
```

**结论的强度不能超过证据的强度。** 只有单一数据集上的提升，就先报告该数据集上的结果；要讨论更广泛能力，需增加相应证据。

## 9. 补充见解：把方法、实验、讨论与结论接回问题

> 本节为整理者补充，补足图片对论文后半部分涉及较少的内容。

### 9.1 方法部分：让读者理解并能够复现

按照“问题定义 → 总体思路 → 关键步骤 → 为什么这样设计 → 实现条件”组织。

- 明确输入、输出、基本假设和适用范围。
- 先给整体流程，再说明模块，避免直接堆公式。
- 定义符号，解释关键公式的作用。
- 区分前人方法、本文改动和常规实现选择，并准确引用。
- 交代影响结果的配置、数据处理和训练或推理流程。

方法的选择理由不等于方法有效的证据。设计动机应在后续实验或理论分析中接受检验。

### 9.2 实验与结果：围绕问题安排证据

每组实验都应有明确问题：验证整体效果、检查组件贡献、解释行为、测量代价，或识别失效条件。

报告时注意：

- 交代数据划分、评价指标、比较对象和关键设置。
- 准确说明哪些结果为自行复现，哪些引用自原论文，哪些条件不同。
- 防止训练与测试信息泄漏。
- 根据领域规范与研究需要报告重复次数、波动和统计分析。
- 不把“数值更高”自动写成“统计显著”。
- 表格和图应注明单位、指标方向及比较条件；正文提炼发现，不逐项复述所有数字。
- 结果不符合预期时，如实报告并调整结论，不能通过挑选结果维持原有叙述。

### 9.3 讨论：解释结果，同时承认限制

讨论应回答：结果支持了哪个判断，与前人有何一致或差异，有什么可能解释，哪些条件下不成立，还存在什么替代解释。

例如，“某模块加入后指标提高”是观察；“该模块通过改善长期规划而起作用”是机制解释。后者需要额外证据，不能由前者直接推出。

局限最好写成“具体限制—对结论的影响—需要怎样的后续验证”，避免只写“未来将进一步改进”。

### 9.4 结论：回到最初的问题

概括本文实际回答了什么、证据支持什么贡献，以及结论的重要边界。不要在结论中首次引入新的核心数据或未经论证的能力声明。

## 10. 补充见解：高效写作顺序与可复用模板

> 本节为整理者补充。以下是工作建议，不是所有论文必须遵循的格式。

### 10.1 建议的工作顺序

1. **列事实和证据**：整理文献、方法、真实结果和未解决事项。
2. **写一页论证提纲**：用简短句子说明问题、现有不足、本文思路、证据和贡献。
3. **建立主张—证据对应表**：找出哪些主张尚无支持，决定补充验证或收缩表述。
4. **完成方法与结果初稿**：先把实际做了什么、得到了什么说清楚。
5. **完善相关工作与引言**：据真实研究范围调整问题定位，避免夸大。
6. **完成讨论和结论，再定稿摘要与标题**：确保全文对同一项研究作出一致表述。
7. **先审逻辑，再审语言，最后审格式**：句子流畅不能替代证据完整。

研究问题仍需在研究开展前明确，并随证据合理修订。上述顺序只是成文建议，不意味着完成实验后再人为制造研究问题。

### 10.2 一页论文论证模板

```text
1. 本文研究什么具体问题？
2. 为什么这个问题值得研究？有哪些事实或文献支持？
3. 前人已经解决了什么？尚未回答什么？
4. 本文研究范围是什么？
5. 本文用什么方法回答问题？为什么适合？
6. 每个研究问题对应哪项实验、数据分析或理论推导？
7. 已经得到哪些结果？哪些仍只是解释或假设？
8. 相比已有知识，本文新增了什么？
9. 哪些条件下结论尚不成立或尚未验证？
10. 用一句话概括本文最有证据支持的贡献。
```

### 10.3 辅助写作任务模板

```text
请根据我提供的研究信息、文献和实际结果，撰写【指定章节】。

研究信息：
【填写第 2 节的信息卡】

章节任务：
【明确这一部分要回答的问题】

写作约束：
- 只采用已提供或已核实的事实与文献。
- 缺失信息明确标记，不编造数据、引用、结果或创新性。
- 区分已有证据、合理解释、研究目标与已完成贡献。
- 先检查研究问题、方法和证据是否对应，再组织段落。
- 按主题和研究关系综合文献，避免逐篇流水账。
- 明确研究边界，删除没有证据支持的强断言。

输出：
1. 章节草稿；
2. 需要补充的证据或资料；
3. 草稿中仍需作者核实的主张。
```

使用辅助工具后，作者仍需核查原始来源、数值和推断，并按投稿要求处理工具使用披露。工具输出的自我检查不能替代作者核验。

## 11. 写完后的检查清单

### 11.1 论证逻辑

- [ ] 能否用一句话说清核心问题？
- [ ] 背景是否服务于这个问题？
- [ ] 是否交代前人已经解决的部分，而不只强调不足？
- [ ] 研究空白是否有具体文献依据？
- [ ] 是否解释该不足为什么值得解决？
- [ ] 每个研究问题是否有对应的方法、数据或分析？
- [ ] 每项贡献是否有对应证据？
- [ ] 摘要、引言、结果与结论是否保持一致？

### 11.2 文献与真实性

- [ ] 文献是否真实存在，引用信息是否准确？
- [ ] 原文是否确实支持引用它的那句话？
- [ ] 是否保留原研究的条件和适用范围？
- [ ] 是否区分研究不足与结果差异？
- [ ] 是否存在虚构数据、夸大结果或未经证实的“首次”声明？
- [ ] 对无法确认的信息，是否明确标记并在提交前处理？

### 11.3 方法与实验

- [ ] 是否解释方法与问题的匹配关系？
- [ ] 是否区分借鉴内容与本文改动？
- [ ] 比较条件是否公平，重要差异是否披露？
- [ ] 关键结果能否追溯到实际实验记录或分析？
- [ ] 是否把相关现象误写成因果或机制证明？
- [ ] 泛化、效率、稳定性等声明是否得到对应验证？
- [ ] 局限与失效条件是否得到如实讨论？

### 11.4 表达与形式

- [ ] 每段是否承担清楚的功能？
- [ ] 是否删除空话、重复和不必要的背景？
- [ ] 引言与相关工作是否避免重复展开？
- [ ] 术语、缩写、符号和指标名称是否一致？
- [ ] 图表是否清晰，引用、编号和正文是否对应？
- [ ] 是否符合目标刊物的篇幅、格式和披露要求？
